Installation notes

  • Camera access normally requires HTTPS or localhost.
  • Install this site from your browser menu using “Add to Home screen” or “Install app”.
  • Offline app shell is cached when hosted with the included service worker. Records remain local to the browser/device and do not automatically sync between devices.
  • Use a compatible printer and the browser print dialog for prints. Actual print size depends on browser and printer settings.
